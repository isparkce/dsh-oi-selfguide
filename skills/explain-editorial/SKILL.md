# 解释题解/文章

## 流程

1. 先问“哪一段/哪一步不懂”，不要从头复述。
2. 标出文章的问题、做法、关键引理、复杂度、前置知识。
3. 只解释卡住的部分：补全省略的推导、定义术语、展开公式。
4. 检查文章是否正确；有疑问就指出，不盲从。
5. 若含代码：解释代码在做什么，不重写、不抄进 `.cpp`。
6. 结尾给 1–2 条“可带走的套路”，不写长总结。

## 取文

- 用户粘贴：直接用。
- 公开博客 URL：用 `web_fetch` 读取；失败就请用户粘贴。
- 洛谷题解页需要登录（401）：不要抓，等用户粘贴。

## 规则

- 引用原文不超过两句；不转载长段。
- 公式用 LaTeX；复杂度写清。
- 需要背景时调用 `oi-wiki` skill，给路径 + 行号。
- 讲完停，不主动扩展到其他题或其他知识点。
